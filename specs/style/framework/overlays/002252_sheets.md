# Side sheets, bottom sheets and select sheets have one frame

`app-side-sheet` must have the inputs `heading: string`, `side: 'end' | 'start' | 'bottom' |
'auto'` (`auto`: end on a wide screen, bottom on a phone), `actions?: readonly Action[]`, the slot
`sheetBody` and the output `action` (`{ key }`). It must have no other way in: no projected content
and no `[sheet-actions]`. The header must show an action with an icon as an icon button, one
without as a text button, and an action with `priority: 'menu'` in the three-dot menu.
`app-select-sheet` must take `options: readonly SelectSheetOption[]` (`null` while they load),
`value` (one choice) or `multi` with `values`, `search?: SearchDef` with `query`, and the main
action (`submitLabel`, `submitIcon`, `busy`), and must report the choice as `picked`. It must list
its choices as rows (001790). A pick dialog, the move sheet and
the link picker must use the select sheet (001380, 001977). A sheet over a sheet must be as opaque
as the first one (000532), the page head must stay in view under an open sheet (000531), and the
page must scroll again when the last overlay closes (001895).

Reason: One sheet frame gives every picker and side panel the same behaviour.

Test: Unit tests and a jest-axe test of `app-sheet` and `app-select-sheet`.
