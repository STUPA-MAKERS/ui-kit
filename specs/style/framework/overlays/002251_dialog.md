# A dialog has a head, a body and a footer group

`app-dialog` must have the inputs `heading: string`, `actions: readonly Action[]` and `size:
'sm' | 'md' | 'lg'`, the slot `dialogBody` and the outputs `action` and `closed`. The footer must
show the actions as one button group with a filled main action (001353) and no button that only
closes (001911). The dialog must keep the focus inside (000513), lie on the top layer (000202),
close on Escape and on Back (000931), and be a near-fullscreen sheet on a phone (000452). An error
text in a dialog must come from the kit (001963).

Reason: Every dialog then has the same frame, focus and footer.

Test: Unit tests and a jest-axe test of `app-dialog`.
