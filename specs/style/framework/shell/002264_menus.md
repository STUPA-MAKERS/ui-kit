# The help, accessibility and account menus come from the shell

The shell must render the help menu from `help.items`, the account menu from `account.items` and
the language control, and the accessibility menu with the display settings (002226) and the link to
the statement. On a wide screen the menus must open from the rail; on a phone they must stand in the
More sheet. Each menu must be black with yellow rows in very high contrast (000617).

Reason: The menus then look and work the same in every app.

Test: Unit tests of each menu with fake items.
