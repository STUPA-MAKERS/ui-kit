# The shell has four frames

The shell must take its frame from the `session` port: `rail` (rail on a wide screen, bottom bar on
a phone), `public` (public header and footer), `bare` (only the page, for a route with `frame:
'bare'`) and `pending` (only the page, so no frame flashes). The rail must show the active item
(000660) and keep its scroll part on a surface (001441). The phone bottom bar must be fixed
(000195), and Mehr and Suche must always be in reach (000407). The footer must show only on a route
with `footer: true` and on public pages (STUPA-Workflow:000199). The skip link must go to the main content
(000510).

Reason: Four fixed frames cover every page of every app.

Test: Unit tests of the shell in each frame.
