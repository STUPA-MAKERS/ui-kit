# App data reaches the shell only through ports

The shell must get the app-wide data it needs only through ports given to `provideFramework()`:
`session` (who is signed in, which gives the frame), `search` (a query gives `SearchHit[]`),
`avatar` (a person gives an image URL), `navMarks` (a key gives a mark, never a count),
`report` (a barrier report or a ticket), `upload` (a file gives a stored reference) and `live`
(the state of the live connection). A port must be a typed interface of the kit with an
observable or a promise as its result.

Reason: The shell stays free of app code, and a second app only writes its ports.

Test: A unit test of the shell with fake ports from `/testing`.
