# Showcase

The showcase app of the kit (spec `S/framework/architecture/002209`). It shows every screen,
overlay and view with fixture data, in each width, theme and contrast mode. It is not
published with the package.

- Build: `npm run build:showcase`
- Serve: `npx ng serve showcase`

A new screen or view gets one page under `src/app/pages/` and one entry in `src/app/pages.ts`.
